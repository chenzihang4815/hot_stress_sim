┌─ 第一步：进入目录 ────────────────────────────────────────────┐
│                                                                  │
│   cd TAP-2.5D                                                   │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌─ 第二步：添加执行权限 ────────────────────────────────────────┐
│                                                                  │
│   chmod +x check_env.sh run_tap.sh quick_test.py                │
│   chmod +x util/hotspot util/*.pl                               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌─ 第三步：检查环境 ────────────────────────────────────────────┐
│                                                                  │
│   ./check_env.sh                                                │
│                                                                  │
│   ✅ Python 3.6+                                               │
│   ✅ HotSpot                                                   │
│   ⚠️  CPLEX (可选)                                            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌─ 第四步：运行 ────────────────────────────────────────────────┐
│                                                                  │
│  【推荐】快速测试（不需要CPLEX）：                               │
│   python3 quick_test.py                                         │
│                                                                  │
│  【完整】优化（需要CPLEX）：                                    │
│   ./run_tap.sh                                                 │
│   或                                                            │
│   python3 sim_annealing.py -c configs/sys_ascend910_local.cfg   │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌─ 第五步：查看结果 ────────────────────────────────────────────┐
│                                                                  │
│   cat ./output/ascend910/output.txt                             │
│   # 输出：                                                      │
│   # 125        # 优化步数                                      │
│   # 78.45      # 最终温度 (°C)                                 │
│   # 8.32       # 平均线长 (mm)                                 │
│   # [25.3, 15.2, ...]  # X坐标                                 │
│   # [30.1, 20.5, ...]  # Y坐标                                 │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
