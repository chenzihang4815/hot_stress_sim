# 工程成果、公式与误差

主路径只做计算和导出。换芯片方案只改 `chips[]` JSON。  
和 COMSOL 比是可选脚本，**不进** `run_case3.py` / `run_case3_stress.py`。

## 1. 现在能算什么

| 层 | 内容 | 入口 | 几何从哪来 |
|---|---|---|---|
| Case 1 | 单硅片稳态热 | `scripts/run_case1.py` | `cases/case1_2d_ic.json` |
| Case 2 | 单片 2.5D 封装热 + 单向热应力 | `run_case2.py` / `run_case2_stress.py` | 手写 `stack[]` |
| Case 3 | N 芯片 2.5D 热 + 应力 + 封装翘曲 | `run_case3.py` / `run_case3_stress.py` | **只填 `chips[]`** |

Case 3 叠层由 `atsim/layout.py` 自动生成：

```
有机衬底（平面 = 芯片包围盒）
  → 硅中介层（同平面，无 TSV）
    → 各芯片（间隙空气，不填硅）
      → TIM（默认盖满包围盒）
        → 铜均热板（包围盒 + 2×11 mm）
          → 铜散热器（均热 + 2×15 mm）
```

换布局：改 `cases/case3_chips.json`（或另存一份）里每颗芯片的 `name, x_mm, y_mm, w_mm, h_mm, t_um, power_W`，然后：

```bat
python scripts/run_case3.py cases/你的.json
python scripts/run_case3_stress.py cases/你的.json
```

**不要改** `atsim/fvm3d.py`（热方程）来迁就布局。力学默认衬底底固定，无 C4。

输出（应力路径）：`results/python_<json名>_stress/`

- `summary.json`：探针、翘曲峰谷、计时
- `mech_probes.csv`：关键点 T / uz / vm / sx / sy
- `warpage_interposer.csv` / `.png`：中介层中面 \(w=u_z\)

## 2. 计算方法与公式

### 2.1 稳态热（`atsim/fvm3d.py`，唯一热 PDE）

\[
\nabla\cdot\big(\kappa\nabla T\big)+P=0
\]

单元中心 3D FVM。空腔格钉在 \(T_\mathrm{amb}\)，固/空界面绝热。对流只在散热器顶：

\[
-\kappa\frac{\partial T}{\partial z}=h(T-T_\mathrm{amb}),\quad
h=\frac{1}{R_\mathrm{convec}A_\mathrm{sink}},\quad R=0.1\,\mathrm{K/W}
\]

界面热导用串联热阻（不要把 \(\kappa\) 调和平均后再除中心距）：

\[
R=\frac{d_p}{2\kappa_p A}+\frac{d_n}{2\kappa_n A},\qquad g=\frac{1}{R}
\]

线性 \(\kappa\) 时一次稀疏求解。大网格先试 CG，失败再 `spsolve`。

### 2.2 单向热弹性（`atsim/elasticity.py`）

温度当场载荷，力不回头改热。

\[
\nabla\cdot\boldsymbol\sigma=0,\qquad
\boldsymbol\sigma=\mathbb{C}:\big(\boldsymbol\varepsilon-\alpha(T-T_\mathrm{ref})\mathbf{I}\big),\qquad
\boldsymbol\varepsilon=\mathrm{sym}\nabla\mathbf{u}
\]

\(T_\mathrm{ref}=T_\mathrm{amb}=318.15\,\mathrm{K}\)。每个固体 FVM 格一个 8 节点六面体。各向同性：

\[
\lambda=\frac{E\nu}{(1+\nu)(1-2\nu)},\quad
\mu=\frac{E}{2(1+\nu)}
\]

von Mises（与 COMSOL `solid.mises` 同一式）：

\[
\sigma_\mathrm{vm}=\sqrt{\tfrac12\big[(\sigma_x-\sigma_y)^2+(\sigma_y-\sigma_z)^2+(\sigma_z-\sigma_x)^2\big]
+3(\tau_{xy}^2+\tau_{yz}^2+\tau_{zx}^2)}
\]

约束：衬底底 \(u_x=u_y=u_z=0\)。其余面自由。无接触、无塑性、无重力。

### 2.3 封装翘曲（`atsim/warpage.py`）

**不是** ATMPlace 的 \(\nabla^4 w\) 薄板方程。从已有 3D \(u_z\) 在中介层中面取样：

\[
w(\boldsymbol r)=u_z\big|_{z=z_\mathrm{IP}}
,\qquad
w_\mathrm{PV}=w_\max-w_\min
\]

布局看峰谷 \(w_\mathrm{PV}\)，不看芯片体内 mises，不看散热器顶 uz。

### 2.4 物性（常数）

| | \(k\) | \(E\) | \(\nu\) | \(\alpha\) |
|---|---|---|---|---|
| 硅 | 130 W/(m·K) | 170 GPa | 0.28 | 2.6e-6 1/K |
| TIM | 4 | 5 GPa | 0.40 | 40e-6 |
| 铜 | 400 | 110 GPa | 0.35 | 17e-6 |
| 有机衬底 | 0.5 | 25 GPa | 0.30 | 15e-6 |

## 3. 误差（Python vs COMSOL）

相对误差定义为 \(\mathrm{MAE}/\mathrm{mean}(|\mathrm{COMSOL}|)\)。棱边 max 不当判据。

### 3.1 热（已对齐）

| 范围 | MAE | 相对 |
|---|---|---|
| Case 1 硅中面 | 0.20 K | ≪ 1% |
| Case 3 芯片中面 2582 点 | 0.34 K | ~0.6% |
| Case 3 中介层中面 5079 点 | 0.31 K | **0.5%** |
| CPU / GPU / HBM 中心 | 0.07–0.14 K | — |

热场可以当载荷用。

### 3.2 芯片体内应力（先前 CSV，\(z=1.175\,\mathrm{mm}\)）

| | MAE | CO 均值 | 相对 |
|---|---|---|---|
| von Mises | 4.19 MPa | 21.5 MPa | **~19%** |
| \(\sigma_{xx}\) | 3.03 MPa | 12.0 MPa | ~25% |
| \(\sigma_{yy}\) | 3.34 MPa | 12.8 MPa | ~26% |
| \(\sigma_{zz}\) | 1.54 MPa | 0.53 MPa | 分母小，相对无意义 |

芯片中心（可信点）：

| | vm Python | vm COMSOL | Δ | 相对 |
|---|---|---|---|---|
| CPU | 17.1 | 14.4 | +2.7 | **+19%** |
| GPU | 18.9 | 15.8 | +3.1 | **+20%** |
| HBM | 20.5 | 18.2 | +2.3 | **+12%** |

Python 中心系统偏高约 **15–20%**。形状和排序一致。绝对 MPa 偏保守（无 C4）。

### 3.3 中介层中面应力（本 CSV，\(z=1.05\,\mathrm{mm}\)，5414 点）

这份文件是 T + mises + sx/sy/sz，**没有 \(u_z\)**，翘曲峰谷还不能对。

| \(\sigma_{yy}\) | 3.17 MPa | 35.5% | 3.17 MPa | 36.7% |
| \(\sigma_{zz}\) | 0.71 MPa | 51.5%（\|sz\| 只有 ~1 MPa） | 0.51 MPa | 45.8% |

芯片正下方（中介层，应看这些点）：

| 点 | T Δ | vm Py / CO | Δvm | 相对 |
|---|---|---|---|---|
| CPU 脚下 | +0.08 K | 16.8 / 14.0 | +2.8 | **+20%** |
| GPU 脚下 | +0.08 K | 18.6 / 15.8 | +2.9 | **+18%** |
| HBM 脚下 | +0.07 K | 20.3 / 18.1 | +2.2 | **+12%** |

| 点 | 问题 |

### 3.4 翘曲

Python 中介层中面：\(w_\mathrm{PV}=0.767\,\mu\mathrm{m}\)（min −0.245 / max 0.521）。  
COMSOL 这份 CSV **无 uz**，百分比对不上。要验证请再导 `solid.w`（μm）同一切面。

### 3.5 怎么读这些百分比

- **热 ~0.5%**：可用。
- **芯片中心 vm ~15–20%**：布局相对比较可用，绝对 MPa 偏高。
- **中介层全域 vm ~30%**：被棱边和间隙拉高，不要用全域 MAE 当精度。
- **棱边 / 四角**：网格加密还会变，丢掉。
- **多少 MPa 正常**（本约定：工作 ΔT~15 K，底固定，无 C4）：中心 **10–30 MPa**；棱边几十～80 MPa 是奇异。硅不会在 20 MPa 断。回流装配（ΔT~200 K）才是几十～两百 MPa / 翘曲几十 μm。

## 4. 主路径 vs 对比脚本

**主路径（换芯片也只跑这些）：**

```bat
python scripts/run_case3.py cases/xxx.json
python scripts/run_case3_stress.py cases/xxx.json
```

只写自己的场和探针，不读 COMSOL 文件，缺 CSV 也不会报错。

**对比（有导出时再单独跑）：**

```bat
python scripts/compare_with_comsol.py          热，芯片中面
python scripts/compare_case3_stress.py         热+应力，芯片中面
python scripts/compare_case3_interposer.py     热+应力，中介层中面
```

把 COMSOL CSV 放到 `results/` 再调用。几何变了就换 JSON 路径，不要把对比嵌进求解器。
