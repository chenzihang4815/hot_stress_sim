# TAP-2.5D 只考虑温度，1050 步完整对照

数据来自 2026-11-10 的一次完整运行，驱动是 `热仿真流水线/src/run_tap_field.py`，原始存档在 `热仿真流水线/runs/superposition/tap_field`。这一份是备份，数字都从存档重算过。

两边走的是同一个退火：温度从 1.0 起，每 50 步乘 0.8，降到 0.01，共 1050 步；90% 的动作是 1 mm 平移，10% 是跳跃并可能旋转；种子 22；只按峰值温度接受，线长不参与。搜索在 16×16 网格上，最优布局用 HotSpot detailed_3D 的 64×64 网格重评，读 Layer 4。中介层 50 mm，粒度 1 mm。起点是紧凑放置，不是 B*-tree，因为那一步要 CPLEX。

全解是每步都跑一次 HotSpot。场叠加是把每个芯粒单独的温升缓存起来再相加，硅填充均匀，所以相加到舍入误差以内是精确的。

线长按 TAP 的公式事后重算：中心到中心的曼哈顿距离乘连线权重，再除以连线总数，单位 mm/wire。连线矩阵取自 `TAP-2.5D/configs/sys_*.cfg`。误差定义为场叠加最优减去全解最优。

## 两边最优布局的误差

误差 = 场叠加最优 − 全解最优，两边都用 HotSpot 64 网格重评。

| 案例 | 峰值温度误差 (K) | 温差误差 (K) | 线长误差 (mm/wire) |
| --- | --- | --- | --- |
| ascend910 | -0.06 | +1.01 | +0.72 |
| micro150 | +0.09 | +1.05 | +5.85 |
| multigpu | -0.35 | -2.61 | +2.38 |

温度只差零点几度，是因为两边接受的都只有温度。线长不在目标里，所以两边的线长可以差几毫米，micro150 差得最多。
