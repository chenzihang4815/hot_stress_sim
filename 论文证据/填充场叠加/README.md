把芯粒压暗。

原始输出在 `复现/ring_n5/`、`复现/ring_n8/`、`复现/ring_n11/`，各有 json、
起点和两个最优的布局、温度场 npz、运行日志。驱动是 `复现/run_ring_anneal.py`，
算子是 `复现/ring_solver.py`。

同一套 n5 在冷边算子上先跑过一次，只接受降温，起点 58.40 °C，全分解 56.03 °C
用 134.5 秒，加速报价 55.83 °C、精确重算 56.48 °C，49.6 秒，2.71 倍，网格最大
1.559 K。原始输出留在 `复现/balanced_n5_greedy/`，图是 `图/面积接近_5芯粒_只降.png`。
那一次用的是冷边算子，数字不和外伸环的混用。更早一次允许接受更热的布局，
加速选出的布局精确重算是 59.09 °C，比起点还高，留在 `复现/balanced_n5/`，不再用。

## 文件

- `run_fill_anneal.py`：驱动。环境变量 `FILL_CASE`（air、epoxy、underfill、silicon）、`FILL_STEPS`、`FILL_OUT`。
- `plot_fill.py`：四种填充的误差场。
- `plot_paths.py`：三条散热路径的瓦数柱状图。
- `plot_share.py`：三条散热路径的百分比堆叠图。
- `rerun_heat_paths.py`：散热路径实验的复现，和 2026-11-13 的存档对账。
- `复现/ten_frozen.py`：10 步材料图不更新的原脚本，和 2026-11-14 的存档对账。
- `plot_ten.py`：10 步误差曲线。
- `plot_ten_stack.py`：10 张误差场按 0.1 透明度叠在一张上。
- `plot_ten_steps.py`：10 步的误差热图，每步一格，画在一张图里。色标收到 ±2 K，90% 的格子误差在 0.6 K 以内，31 K 的峰值会把浅的地方压没，超出的格子画成两端的深色。
- `复现/run_accel_56789.py`：5 到 11 芯粒，材料场加速对每步全部分解。
- `plot_accel.py`：加速选出的布局上，报价相对精确场的误差柱状图。
- `复现/spreader_ring.py`：外伸环的验证，对同一套硅填充和 HotSpot 比。
- `复现/ring_solver.py`：带 8 个外伸节点的四层算子，退火用这个。
- `复现/run_ring_anneal.py`：外伸环算子上的材料场加速，n5、n8、n11。
- `plot_ring_bars.py`：外伸环三套的用时和误差柱状图。
- `runs/{填充}/`：`summary.json`、`trace.json`、`best_layout.json`、`grids.npz`。
