# V-B 场叠加对全解

退火、移动和初始布局都用 TAP-2.5D 自己的，只换温度这一入口。种子 22。

`同网格/` 里中文稿图 3 是 `用时与误差.png`。64 网格、120 步：全解 1316 到 1478 秒，场叠加 659 到 855 秒，快 1.54 到 2.08 倍。micro150 的重评峰值差是 +2.49 °C，用种子 22，不要换成种子 23。原因是第 62 步：全解 102.62 °C 拒绝，场叠加 102.60 °C 接受。

ascend910 走完 1050 步，全解计算时间 45507 秒，场叠加 12306 秒，是 3.70 倍。原始墙上时间更长，中间有一段休眠，只引用计算时间。

`两表/` 是 120 步和 1050 步的时间和温度对照。

`跨网格_不引用/` 是 16 网格的场叠加对着 64 网格的全解。中文稿不引用这组倍数。
