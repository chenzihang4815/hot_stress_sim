# V-E 完整流程

5、6、7、8、9、11 颗芯粒，硅和环氧各一遍。起点、退火最优、调频之后分开报。频率倍率 0.5 到 2.5，步进 0.1，只缩动态功耗。2.5 是上限，不是搜索自己停在那里。

`闭环全流程/` 有退火逐步曲线。温度是按带外伸环的算子，在当时被接受的布局上重算的。线长和目标值仍是当时的搜索记录，搜索没有重跑。

`只收更优/` 是另一套接受规则。热图和 `python_maps`、`compare_bars` 已按外伸环重画。HotSpot 柱、ATSim 柱、应力柱还是报告里的旧数，那两次没有重跑。

并排图里三种温度不是同一个量。Python 柱是最热芯片的块平均，HotSpot 柱是块平均而且缝按硅，ATSim 柱是芯片柱平均。门槛用的是 ATSim 芯粒层最热一格，不在这根柱上。应力柱没有乘 0.892。

`帕累托/` 是环氧 0.8 加外伸环重算的云。中文稿第 V-E 节没有单独写这一组。n7 没有单张图，在 `帕累托_n7_n9.png` 的左面。n11 是 300 个布局。`*_scan_ring.json` 是新数，原来的 `scan.json` 还在原目录。

`配置/n5_silicon_freq_hotspot.config` 是闭环实际写出的 HotSpot 配置：96 mm，`r_convec` 0.0390625，芯片层导热 130，64×64，次路径关。`python_ring.json` 是重算后的 Python 读数。

不限频率的那一次没有收进这里。它在 `论文证据/闭环全流程_只收更优_不限频率`，布局是冻住的，没有新的退火。
