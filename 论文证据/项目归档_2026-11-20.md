### 0.3 应力有两个口径

ATSim 的 von Mises 相对 COMSOL 线性六面体系统性偏高。七个布局的芯片中心相对差平均是 +12.1017%。`热应力python工程_最终/scripts/run_case2_stress.py` 和 `run_case3_stress.py` 在写出 MPa 时乘

```
VM_SCALE = 0.892047 = 1 / (1 + 12.1017/100)
```

只乘写出的数。求解器、网格、材料、温度场都不乘。乘完平均为零，这是系数的定义，不是一次新的对照。不能写成「ATSim 与 COMSOL 吻合」。

闭环和帕累托里的应力**不乘**这个系数。门槛是求解器自己的数，200 MPa。HBM 不进应力门槛。

## 1. ATSim 对 COMSOL

出处：`热应力python工程_最终/docs/应力版本说明.md`，`热应力python工程_最终/README.md` 的「精度」一节。副本在 `论文证据/第五章/chapter1/`。中文稿的表 I、表 II 还是占位，这里没有另做一张表。

热求解是笛卡尔 FVM，`atsim/fvm3d.py`。力是 Wilson 线性六面体：节点温度由格心平均到角点，2×2×2 高斯点的热载荷和应力再平均，`atsim/elasticity.py`。hex20 和 tet10 关不上多芯片芯片中心的那一截误差，不是主路径。

单向耦合，先热后力。参考温度和环境都是 45 °C。衬底底面整面固定。没有 TSV，没有 C4。对流只在散热器顶。芯片间隙在这套对照里是空腔，不是默认填硅。

芯片中心温度差在 0.3 K 以内。

应力对七个布局的芯片中面 z = 1.175 mm、COMSOL 线性六面体的精确节点取相对差 (ATSim − COMSOL) / COMSOL，七个等权再平均，+12.1017%：

| 布局 | 校正前 |
| --- | ---: |
| Case 2，单芯片 8 mm | −2.12% |
| 单芯片 18 mm | +19.52% |
| 四芯片 | +9.71% |
| 三芯片基准 | +14.42% |
| G1 | +13.92% |
| G2 | +16.74% |
| G3 | +12.52% |

20 / 25 / 30 W 是三芯片基准的同一布局，相对差不变，没有再计一次。应力对温升线性，换功耗仍用这一个系数。

乘完之后平均为零。散布还在。Case 2 从 −2.12% 变成 −12.68%，变差。其余大约落在 −2% 到 +7%。

已有探针核对过，没有重算。三芯片基准 A 的中心：12.6767 × 0.892047 = 11.3082 MPa，COMSOL 10.6520，校正后 +6.16%。Case 2 的中心：7.2715 × 0.892047 = 6.4865 MPa，COMSOL 7.4287，校正后 −12.68%。

不要用芯片棱边的 mises。不要把中介层十字缝下的点当精度代表。相对 COMSOL 的二次四面体还要再高约一成，因为单元更软。

## 3. 填充、散热路径、老化

工具是算子 B，五层 Python。不是 HotSpot，不是 ATSim，也不是后来补上外伸环的四层算子。绝对温度不和别的求解器放进同一张表。这一组没有按外伸环重画。

记录在 `论文证据/填充场叠加/README.md`，图在 `填充场叠加/图/`。副本在 `第五章/chapter4/`。

模型：中介层 100 µm 硅，芯片 150 µm，TIM 20 µm，铜均热片 1 mm，热沉 6.9 mm。芯片格子固定硅 130，变的是缝。底面先过 1 mm、导热 0.5 的有机层再接到环境，中介层最外一圈用 1e4 W/K 接到 45 °C。对流系数和闭环相同，2777.8 W/m²K，但板的边界条件不是闭环那一套。

### 3.2 老化

老化只把 TIM 的导热从 4.0 改到 4/3，厚度不变，热阻 3 倍。没有放进退火。没有算漏电的那一组和算了漏电的那一组要分开。

四芯粒那一组算了漏电，写在 `复现/填充与路径_工作状态.md`。漏电按 McPAT，相对 350 K 乘 `exp(7000·(1/350−1/T))`。Penryn 基准 11.31 W，3070 基准 18.51 W，另有 32.33 W 不随温度变。HBM 和 CIM 没有温度漏电。图上的 90 °C 余量是这个 Python 场上的余量，不是 ATSim 门槛。

次路径份额（底加边），新鲜到老化：空气 10.4% 到 11.3%，有机 22.9% 到 23.2%，环氧 26.4% 到 26.5%，底填 28.3% 到 28.2%，硅 69.0% 到 59.3%。硅的主路从 31.0% 回到 40.7%，侧边从 64.0% 回到 52.5%。不要写成「老化提高了次路径份额」，硅这一行是下降的。

ascend910 那一组不算漏电，不算热流占比。布局是 `tap场叠加/runs/ascend910_16_full/init.json`，六颗，总功耗 350 W。芯粒 0 是 14.5×31.4 mm、256 W。几何按 50 mm 铺到 64 格，格 0.78125 mm，电阻仍用求解器自己的 1.125 mm。绝对温度不能和 TAP、也不能和四芯粒那一组相减。组内的老化减新可以比。

只有主路径时，大芯片涨约 +2.64 °C，空气和硅几乎一样。硅、新鲜、大芯片是 80.36 °C，老化后 82.99 °C，+2.63 °C。加上次路径后，256 W 的芯片空气涨 +2.33 °C、硅涨 +4.56 °C；14 W 的芯片是 +0.14 °C 对 +2.09 °C。大芯片对 14 W 的功率比 18.29，密度比 6.75；只有主路径、空气时涨幅比 4.73。

## 5. 闭环

驱动是 `热仿真流水线/src/run_closed_loop_suite.py`。5、6、7、8、9、11 颗，硅和环氧各一遍，共 12 组。每组是 CPU + GPU + CIM，另有 HBM。

### 5.1 目标函数和接受

目标函数不叫代价。三项各占三分之一，都除以该组起点，起点是 1：

```
J = ((Tmax − 45) / dT0 + grad / g0 + 线长 / wl0) / 3
```

线长是中心到中心的曼哈顿，mm/线。网表在退火前冻结：每颗 CPU 或 GPU 和 HBM 双向各 1024，每颗存算和第一颗 CPU 双向各 128。这是假设的连接，不是 gem5 给的。

应力不在 J 里，也不在接受里。

搜索是 40 步，种子 11。改芯片固定 10%，只换 CPU 和 GPU 的型号，CIM 不换，HBM 的功耗随 CPU 和 GPU 的颗数重算。其余 90% 分给布局：旋转固定占这 90% 的 10%，微调的份额从 10% 线性升到 70%，剩下的由大跳和交换位置平分。微调的步长是 1、1、2、3、4 格里抽一个。

更好或相同的步必收。更差的步，默认按 `0.20 × (1 − step/40)` 收，第一步 0.20，最后一步 0。`SUITE_WORSE_P=0` 时更差的步不收。两套记录就是这个差别。

硅填充每步只换功耗，矩阵按整层硅分解一次。环氧不是八次修正：起点存一份环氧减硅的残差，后面每步加上它，不再更新。终点残差是这个残差和终点重算的差。

### 5.3 冻住之后的门槛

ATSim 在布局冻住之后跑，搜索过程里不进接受。一次应力求解大约 36 秒，12 组必须串行，一台机器 12 GB 内存，fenicsx 一次只能跑一个。

门槛：2 mm 网格上芯粒层最热一格低于 90 °C，正常芯粒内部 von Mises 低于 200 MPa。应力不乘 0.892。HBM 不进应力门槛。

ATSim 的封装比 Python 多两层：1 mm 有机衬底，导热 0.5，和 100 µm 硅中介层。芯粒区 2 mm，外围 8 mm。垂向分层是芯粒 3、TIM 1、均热片 3、热沉 4、衬底 3、中介层 2。热求解用常数导热 130。环氧的导热用 0.8。弹性模量、泊松比和热膨胀没有环氧的卡片，案例里借用的是已有有机材料的力学数，只写在该案例的 json 里，默认材料表没有改。

频率是布局冻住之后的另一段。CPU 和 GPU 的倍率从 0.5 到 2.5，步进 0.1，只缩放动态功耗。先往上加，加完若最热格超过 90 °C，就把动态功耗最大的那一颗降 0.1，最多 12 次。应力超过 200 MPa 但在 220 MPa 以内，最多修六次，三次真的下降就停。超过 220 MPa 的保持原样，标成没过，不丢弃。

2.5 是设定的上限，不是搜索自己停住。这个上限的文献出处还缺，稿子里是【待补】。

## 8. 更早的实验，论文不直接引用

## 9. 论文现在能说的话

1. TAP 同网格，B*-tree，120 步：1.49 到 2.08 倍。除 micro150 的 64 网格外，温差在 0.04 °C 以内。+2.49 °C 要连同第 62 步的 0.02 °C 一起写，用种子 22。1050 步的 3.70 倍只属于另一套退火的 ascend910、64 网格，温度在 116 °C，而且要写明扣掉了 43961.3 s 的休眠。
