# 暂时定为最终闭环的效果

2026-11-18 定下来：论文里闭环的效果先用这一套，不用 `论文证据/闭环全流程`。那一套允许接受更差的步，留在原地，不删，也不拿来替换这里的数。这一条是暂时的，搜索没有重跑。

## 流程

`闭环全流程_只收更优`。5、6、7、8、9、11 颗，硅和环氧各一遍，共 12 组。种子 11，内层 40 步。更好或相同的步接受，更差的步不接受。

目标不叫代价。三项各占三分之一，都除以该组起点，起点是 1：

```
J = ((Tmax - 45) / dT0 + grad / g0 + 线长 / wl0) / 3
```

线长是中心到中心的曼哈顿，mm/线。网表在退火前冻结：每颗 CPU 或 GPU 和 HBM 双向各 1024，每颗存算和第一颗 CPU 双向各 128。应力不参与接受。

硅填充每步只换功耗，矩阵按整层硅分解一次，终点残差是 0。环氧不是八次修正：起点存一份环氧减硅的残差，后面每步加上它，不再更新。六组环氧的终点残差是 0.335 K 到 0.799 K，最大是 11 颗的 0.799 K。

布局冻住之后才调频率。CPU 和 GPU 的倍率从 0.5 到 2.5，步进 0.1，只缩放动态功耗。2.5 是设定的上限。12 组调频之后都过了门槛：ATSim 芯粒层最热一格低于 90 °C，正常芯片内部 von Mises 低于 200 MPa。应力不乘 0.892。没有一组因为应力把频率按住。除了 11 颗的 Cb 停在 2.2，其余 CPU 和 GPU 都在 2.5。

吞吐按倍率相乘，不是重新跑 kernel。CPU 是核数 × 主频 / 3700 MHz × 倍率，3700 是 Penryn 的主频，只用来当 1。GPU 是该卡目录里的指令率乘倍率。两种单位不加总。CIM 和 HBM 不调频。5 颗硅：T2 从 3.03 到 7.57，3070 从 19.08 到 47.70 Ginst/s。
