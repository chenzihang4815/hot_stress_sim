# 16 组三芯片硬件组合（每组都是 CPU + GPU + CIM）

布局一律 L-BFGS。任务侧：CPU 都是 gem5 ARM `hello`；GPU 都是 Accel-Sim backprop；CIM 用 AccelForge 各自 YAML 自带的小 matmul。

笛卡尔积：4 种 CPU × 1 种 GPU × 4 种 CIM = 16。

## GPU（16 组同一颗）

| 项 | 值 |
|---|---|
| 工具 | Accel-Sim + AccelWattch SASS |
| 机器配置 | SM7_QV100 / `gpgpusim.config`（80 SM） |
| 任务 | Rodinia `backprop`，kernel `_Z22bpnn_layerforward_CUDAPfS_S_S_ii` |
| 功耗 | `kernel_avg_power` = **72.955 W** |
| 面积 | AccelWattch **不算面积**；暂用 GV100 裸片 **815 mm²**（文献，不是仿真器输出） |
| 源文件 | `成功运行备份/Accel-Sim/官方下载/run_backprop/accelwattch_power_report.log` |

## CPU（gem5 + McPAT，一种 CPU，换机器配置）

任务全部是仓库自带 `tests/test-progs/hello/bin/arm/linux/hello`。功耗 = Runtime Dynamic + Total Leakage。

| id | gem5 机器 | cache | 面积 mm² | 漏电 W | 动态 W | 合计 W | McPAT 输出 |
|---|---|---|---:|---:|---:|---:|---|
| **L2** | `se.py` TimingSimpleCPU | L1+L2 | **13.635** | 0.784 | 0.084 | **0.868** | `gem5/output/mcpat_from_gem5.txt` |
| **noCache** | `se.py` TimingSimpleCPU | 无 | 2.900 | 0.620 | 0.057 | **0.676** | `gem5/多案例/01_se_timing_无cache/mcpat.txt` |
| **atomic** | `se.py` AtomicSimpleCPU | 无 | 2.900 | 0.620 | 0.524 | **1.144** | `gem5/多案例/02_se_atomic_无cache/mcpat.txt` |
| **starter** | `configs/example/arm/starter_se.py --cpu atomic` | 无 | 2.900 | 0.620 | 1.031 | **1.651** | `gem5/多案例/03_starter_se_atomic/mcpat.txt` |

gem5 指令（均在 `gem5-stable/gem5-stable`，ARM `gem5.opt`）：

```text
L2:      se.py --cpu-type TimingSimpleCPU --caches --l2cache --cmd .../hello
noCache: se.py --cpu-type TimingSimpleCPU --cmd .../hello
atomic:  se.py --cpu-type AtomicSimpleCPU --cmd .../hello
starter: configs/example/arm/starter_se.py --cpu atomic -- .../hello
```

L2 面积大是因为 McPAT 里有 **10.72 mm² L2**；后三种无 cache，Processor 只有约 2.90 mm²。starter 动态功耗最高。

## CIM（AccelForge）

功率 = `energy_J / latency_s`。面积 = 各组件 `area_m2` 之和。

| id | arch YAML | 任务 | 面积 mm² | 功耗 | 备注 |
|---|---|---|---:|---:|---|
| **basic** | `examples/arches/compute_in_memory/basic_analog.yaml` | YAML 自带，1024 MAC | **0.047** | 2.63 mW | ADC 占能量和面积大头 |
| **jia** | `jia_jssc_2020` | builtin，589824 MAC | **4.281** | 2.77 mW | 面积最大，和 CPU 核同量级 |
| **colonnade** | `colonnade_jssc_2021` | builtin，16384 MAC | 0.231 | **41.2 mW** | CIM 里最热 |
| **wang** | `wang_vlsi_2022` | builtin，1024 MAC | 0.122 | 26.0 mW | |

源：`成功运行备份/AccelForge/cim_basic_analog/output/result.json` 与 `more_combos/output/summary_table.json`。
